## Research Question & Scope

> Can an independently bounded mean photon number $\tr(\rho\hat n) \le \bar n_{\max}$ turn two displaced binary (click/no-click) optical measurements into a useful majorization witness of nonclassicality, with explicit detector calibration and distribution-free finite-sample guarantees?

**Locked six-week scope:** One optical mode, two opposite real displacements $\alpha_\pm = \pm a$ ($a>0$), a calibrated on/off detector (efficiency $\eta$, Poisson dark-count mean $\nu$, distinct from pre-displacement source transmission $T$), all detection windows retained (no postselection or PNR reconstruction), and an independent upper bound $\bar n_{\max}$ on source energy before displacement. Out of scope for this first manuscript: multimode models, steering protocols, cryptographic security claims.

## Quick Start & Reproducibility

On this workstation, use the `quantumcomputing` conda environment (NumPy/SciPy/Matplotlib installed):

```bash
conda activate quantumcomputing

# 1. Regenerate benchmark JSON and CSV files in data/
python code/note_calculations.py

# 2. Run the 12 baseline unit checks
python -m unittest discover -s code/tests -v

# 3. Run the Week 1 audit & cross-repo verification checks
python code/week1_audit_verify.py

# 4. Compile Marcelo's technical note (from notes/)
cd notes && latexmk -pdf -interaction=nonstopmode -halt-on-error quantum_light_technical_note.tex
```
